# ashar-site
Motivation - https://karaj.uk/
Personal portfolio for **ashar khan**.

Built with:

- Vite
- React
- TypeScript
- Tailwind CSS

## Content

Edit `frontend/src/data/siteData.ts` to update the content.

## Development

```bash
cd frontend
npm install
npm run dev
```

Build for production:

```bash
cd frontend
npm run build
```
